# 濱線 Hamasen H.M.S — EPK

> EPK 電子新聞資料袋準備清單

Electronic Press Kit 網站。單頁 HTML，支援中文 / English / 日本語三語切換，瀏覽器自動偵測語言。

## 內容

- 樂團簡介（中文 + 英文版本）
- 音樂風格描述與代表作連結
- 高解析度照片（至少 3–5 張）
- Demo 或現場演出錄音連結
- 過往演出紀錄（場地、日期）
- 獎項（街聲編輯推薦、週排行、Song of Day?、比賽）
- 社群媒體連結與追蹤數
- 聯絡人姓名與 Email

## Usage

### 更新`script.js` 頂端的資料陣列

- 推薦試聽曲目：`TRACKS`
- 現場影片：`VIDEOS`
- 社群連結（Spotify、YouTube）：`SOCIAL`

### 更新引言來源（可選）

目前 3 個語言區塊的引言來源都是 `— 2026 —`。
若日後有媒體評論或具名引用，可替換為：

```html
<div class="quote-note">— 媒體名稱 / 評論者 · 2026 —</div>
```

## 未來改版參考：EPK 製作重點

> 整理自 [fabric.so — How to Make an EPK](https://fabric.so/zh/blog/how-to-make-an-epk-electronic-press-kit)，供未來樂團更成熟後改版 EPK 時使用。

### 一、EPK 是什麼

EPK（Electronic Press Kit）是一個可分享的整合包，讓音樂產業專業人士（媒體、唱片公司、經理人、經紀人、音樂節策展人）一次掌握藝人的簡介、音樂、照片、媒體報導、數據與聯絡方式。現在多以可即時載入的網頁形式呈現，取代過去的 PDF 附件。

**什麼時候需要：** 發行音樂、辦演出、向媒體/廠牌/音樂節/經紀人推廣時。

### 二、必備內容清單

- **藝人簡介**：第三人稱，2–3 段，約 300 字以內。準備完整版與簡短版。
- **音樂作品**：1–2 首最能代表當下風格的曲目（串流連結最方便）。
- **音樂錄影帶**：1–2 支最佳作品，有助策展人評估舞台與視覺。
- **照片**：3–5 張高解析度（300 DPI、最長邊 ≥ 2000 像素），含個人/團體肖像與現場演出照，並提供下載連結。
- **媒體報導與推薦**：出版物名稱、簡短引言、原文連結。沒有就不列，不要用冷門來源充數。
- **數據與社群證明**：只列亮眼數字（串流數、每月聽眾、知名歌單入選、售罄演出）。
- **演出歷史與近期演出**：值得關注的過往與即將到來的場次。
- **聯絡資訊**：預訂、公關、經紀分開列，姓名/電郵/電話，放在醒目位置。

### 三、選填但實用

- 技術需求與舞台配置圖（PDF 下載）
- 專輯封面美術
- 主打曲目歌詞（僅在需要時）
- 一頁摘要（One-sheet）供快速瀏覽

### 四、撰寫技巧

- **簡介從聲音寫起**：避免只用「獨立」「另類」等空泛標籤，改用樂器、影響、能量、氛圍等具體描述。
- **開頭放最強資歷**：與知名藝人同台、重要音樂節、重要媒體報導應在第一段點出。
- **著重近況與未來**：讀者在意你現在在做什麼，不是多年前的事。
- **精簡**：約 300 字以內，尊重專業人士的時間。
- **照片值得投資**：最常被忽略卻最影響觀感的元素，一次專業拍攝可用一年以上。
- **曲目精選**：EPK 是精華展示，不是完整資料庫。
- **語氣對齊風格**：龐克樂團不要寫得像新聞稿。

### 五、常見錯誤

- 從小時候或何時學樂器寫起
- 把舊的發行/巡演寫成「即將推出」
- 數據或媒體提及太少時硬塞
- 聯絡資訊埋太深
- 照片品質不佳（模糊手機照）
- 檔案過重或音訊/影片自動播放
- 用 PDF 附件寄送（增加阻力、無法嵌入音訊影片）

### 六、託管方式

- **自有網站**：在官網設 `/press` 或 `/epk` 頁面（本專案採用此方式）
- **專門 EPK 平台**：Sonicbids、Bandzoogle、ReelCrafter、EPKBuilder 等

### 七、推廣策略

- 郵件個人化，針對對方的文章/節目寫具體開場
- 郵件中直接附最佳曲目串流連結，EPK 連結留給想深入了解的人
- 郵件保持 3–5 句
- 未回覆可一週後禮貌跟進一次，不過度追蹤

### 八、更新頻率

每次重大發行、演出、媒體報導或串流里程碑後更新，至少每幾個月檢視一次。
